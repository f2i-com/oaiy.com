Models

Pick a file or folder and OAIY reads its headers to work out what it is. Language models go to chat, image models to images, video models to videos. Parts such as projectors, adapters, encoders and tokenizers attach to the model that needs them.

Nothing to add yet? Get models downloads ready-to-run models and adds them here.

Add a model

Reads GGUF (LLMs, Qwen Image, vision projectors), safetensors (SDXL, Qwen Image, LTX 2.3/2.5, LoRA adapters, text encoders, VAEs), diffusers and EXL3/DeepSeek folders, Pixal3D and DINOv3 folders (3D models), and tokenizer.json. Pickled .bin/.pt files are refused because loading them can run code; NAF's naf_release.pth and Real-ESRGAN's RealESRGAN_x4plus.pth are the exceptions, read by oaiy's own reader, which runs nothing from the file.

Get models

Ready-to-run models, downloaded from Hugging Face. Each goes into a folder of its own and is added to your models when it finishes. Pause any time: a download picks up where it stopped, even after a restart.

Memory

Choose where weights live for each kind of job. Keeping blocks on the GPU is fastest, keeping them in RAM costs one PCIe copy per block, and streaming from the SSD saves both kinds of memory. The output is identical either way; only speed and memory use change.

Sharing GPUs

Which GPUs the language models use, and which one image, video, speech, music, sound effect and 3D model jobs use. A model can also have GPUs of its own (under Models), e.g. a big one across both.

Language model GPUs

Language model memory

Mixture-of-experts models keep their shared weights on the GPU, cache hot experts in VRAM and RAM, and read the rest from the SSD a token at a time.

Endpoints

The API other apps call. Each route maps a path and method to a service and the dialect it speaks: OpenAI, or oaiy's job API for tools such as coder-cli.

Server

Web pages can reach this port too, so without an API key, browser requests are refused unless their origin is listed. Apps, scripts and SDKs outside a browser are unaffected.

Use 0.0.0.0 to serve your network, and set an API key when you do. Address changes apply the next time OAIY's engines start.

Language model

WebGPU runs every model on any Direct3D 12, Vulkan or Metal GPU: weights past the limit stay in RAM and run on the CPU. A Mac's own GPU shares the computer's memory: left empty, it holds what a card with two thirds of that memory would.

eGPU

macOS has no driver for a graphics card in a Thunderbolt enclosure. tinygrad reaches one through its TinyGPU app, and with that set up, a model ticked "On the eGPU" under Models is answered on the card, and by this Mac's own GPU whenever the card is not there.
